00 — Overview

Visual direction

Fieldnote helps ops teams track workflows and SLAs. The UI is calm and scannable: white canvas, cool gray surfaces, indigo for primary actions and selected rows. Body text stays 14px; decorative chrome is minimal.

05 — Guardrails

Do's and Don'ts

Do

  • Use primary for one main action per panel
  • Keep table body at 14px
  • Right-align numeric SLA columns
  • Show workflow ID in mono

Don't

  • Don't use pill primary buttons in app chrome
  • Don't add a second accent for decoration
  • Don't use display type in table cells
  • Don't rely on color alone for status
